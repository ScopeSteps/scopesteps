# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/ScopeSteps/scopesteps/security/advisories/new).
Do not open a public issue, pull request or discussion for a security problem.

Include what you found, how to reproduce it, and what an attacker could do with it. Use synthetic
data only in your report: never send real meeting content, credentials or personal data.

We aim to acknowledge a report within 5 working days and to agree a disclosure date with you once
the issue is understood.

## Supported versions

ScopeSteps is a proof of concept with no releases yet. Only the latest `main` is supported.
