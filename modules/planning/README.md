# planning (reserved, phase P2)

Planning scenarios: effort, capacity, delivery and ROI estimates built **only** from explicit
inputs (effort ranges, team capacity, dependencies, rates and benefit assumptions). Shows
uncertainty or "insufficient information" instead of inventing numbers.

Not part of the P0 POC. This folder reserves the name. When work starts, give it the same
layout as the other modules (`pyproject.toml`, `src/scopesteps/planning/...`) and remove it
from `exclude` in the root `pyproject.toml`.

See `docs/proposals/ScopeSteps Technical Proposal.md`, section 10.
