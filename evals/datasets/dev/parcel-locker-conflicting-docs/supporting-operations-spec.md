# Operations specification: Parcel Lockers

Version 1.3, 24 October 2026. Written by the operations team.

Parcels that are not collected wait five days in the locker, then go back to the depot.

A customer can extend the collection time once, by two days.

Each locker delivery costs the customer one pound, added at checkout.

Parcels must fit the large locker door: 60 by 40 by 40 centimetres.

Lockers are opened with a six-digit code sent by text.
